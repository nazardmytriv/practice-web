# SHOP. — сайт магазину дизайнерських меблів та предметів інтер’єру

Курсовий проєкт з веброзробки.
**Студент:** Назар Дмитрів, **група:** ПІ-23-03

**Сайт:** https://nazardmytriv.github.io/practice-web/

## Опис

Інтернет-магазин дизайнерських меблів та декору. Каталог товарів і заявки
зберігаються в базі даних Supabase, сторінки адаптовані під мобільні пристрої
(підхід Mobile First).

## Сторінки

| Сторінка | Файл | Що містить |
|---|---|---|
| Головна | `index.html` | банер, переваги, популярні товари з БД, слайдер відгуків, статистика |
| Магазин | `products.html` | каталог з БД, фільтр за категорією, пошук, сортування, модальне вікно замовлення |
| Про нас | `about.html` | історія, місія, команда |
| Послуги | `services.html` | послуги, етапи роботи, акордеон «Часті питання», заявка |
| Контакти | `contact.html` | контактні дані, форма заявки |
| Помилка 404 | `404.html` | сторінка неіснуючої адреси |

## Функціонал

- Мобільне меню (burger) на всіх сторінках
- Динамічне формування карток товарів із даних Supabase (`fetch`, обробка помилок, повтор запиту)
- Фільтр за категорією, пошук за назвою та сортування за ціною (також пошук із шапки)
- Модальне вікно із формою замовлення: закриття кнопкою, кліком поза вікном та клавішею Escape
- Валідація форм на клієнті (ім’я, email, телефон, довжина повідомлення)
- Запис заявок у таблицю `requests` (операція додавання даних)
- Кошик: додавання товарів, зміна кількості, підсумок, збереження в `localStorage`, оформлення замовлення (заявка зі складом кошика записується в `requests`), анімація лічильника в шапці
- Слайдер відгуків (дані з масиву об’єктів) та акордеон
- SVG-спрайт для іконок, зображення у форматі WebP

## Технології

HTML5, CSS3 (Flexbox, Grid, CSS-змінні), JavaScript (ES6+, без бібліотек),
Supabase (PostgreSQL + REST API), GitHub Pages.

## База даних (Supabase)

- `products` — товари: `id`, `name`, `price`, `category`, `image_url`, `description`, `is_sale`
- `requests` — заявки: `id`, `name`, `email`, `phone`, `message`, `product_id` (посилання на `products`), `created_at`

Доступ обмежено політиками Row Level Security: анонімний користувач може лише
читати `products` і додавати записи в `requests`. Для клієнта використовується
публічний (publishable) ключ; секретні ключі в проєкті не зберігаються.

## Запуск локально

Відкрити папку проєкту у VS Code та запустити `index.html` через розширення
Live Server. Відкриття файлу подвійним кліком не підходить: частина функцій
(запити до бази, спрайт іконок) потребує локального сервера.
